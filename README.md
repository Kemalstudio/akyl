# Akyl

Офлайн голосовой ассистент для Android: звонки и SMS голосом, без интернета
и без отправки голоса на чужие серверы.

Цель по скорости — от конца фразы до начала звонка **не больше 1 секунды**
на телефоне среднего класса.

```
Вы: Позвони маме
Akyl: Звоню Маме                      — звонок уже идёт

Вы: Напиши Мерет что я опаздываю
Akyl: Отправить Мерет: я опаздываю?   — SMS без подтверждения не уходит
Вы: Да
Akyl: Отправлено
```

## Состояние: этап 1 закрыт

Работает весь конвейер команды, кроме распознавания речи: фраза пока вводится
с клавиатуры, а на её месте стоит интерфейс `SpeechToText` — подключение
T-one идёт этапом 2.

| Что | Состояние |
|---|---|
| Намерения CALL, SMS, CONFIRM, CANCEL, SELECT | на правилах, 96% строк под тестами |
| Поиск контакта: падежи, ласковые формы, транслитерация | готово |
| Уточнение при нескольких совпадениях | готово |
| Подтверждение SMS, отмена, контекст 60 секунд | готово |
| Звонок и SMS через Kotlin | готово |
| Экраны, тема, фирменный знак | готово |
| Распознавание речи (T-one) | этап 2 |
| Своя NLU-модель | этап 3 |
| Фраза активации «Эй, Акыл» | этап 5 |

Подробный план — [docs/roadmap.md](docs/roadmap.md).

## Запуск

```bash
cd app
flutter pub get
flutter run            # нужен Android 10+ (API 29)
```

Тесты и проверки:

```bash
cd app
flutter analyze                                   # должно быть чисто
flutter test                                      # 114 тестов
flutter test --coverage                           # покрытие ядра ~89%
flutter test --update-goldens test/presentation   # пересобрать снимки экранов
```

Модели для этапа 2 — [docs/models.md](docs/models.md):

```powershell
powershell -ExecutionPolicy Bypass -File tools\fetch_models.ps1
```

Иконки и фирменный знак пересобираются из кода:

```bash
python tools/make_icons.py     # нужен Pillow
```

## Устройство

```
речь → VAD → STT → NLU → диспетчер диалога → навык → Kotlin → звонок/SMS
                                     ↓
                              голосовой ответ
```

Каждый слой стоит за интерфейсом: `RuleBasedNlu` меняется на `MlNlu`, а
`ManualTextStt` на `TOneStt` правкой одной строки в `app/lib/main.dart`.
Ядро — чистый Dart без Flutter и Android, поэтому все сценарии из ТЗ
проверяются юнит-тестами: см. `app/test/domain/scenarios_test.dart`.

Подробнее — [docs/architecture.md](docs/architecture.md), решения и их причины —
[docs/adr/](docs/adr/).

## Приватность

Голос, распознанный текст и контакты не покидают телефон. Разрешения
`INTERNET` в релизном манифесте нет — это можно проверить, и это проверяет CI.
В debug- и profile-сборках его добавляет сам Flutter, иначе не работает
hot reload.
