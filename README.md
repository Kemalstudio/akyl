# Alym AI (Akyl)

Голосовой помощник для Android, который слушает обращение «Макс» с телефона
на столе — без открытия приложения и без интернета. Как устроен голос,
фоновый режим и что ограничивает Android — [docs/voice.md](docs/voice.md).

Офлайн голосовой ассистент для Android: звонки и SMS голосом, без интернета
и без отправки голоса на чужие серверы.

Цель по скорости — от конца фразы до начала звонка **не больше 1 секунды**
на телефоне среднего класса.

```
Вы: Позвони маме
Akyl: Звоню Маме                      — звонок уже идёт

Вы: Позвони маме по громкой связи
Akyl: Звоню Маме, по громкой связи

Вы: Напиши Мерет что я опаздываю
Akyl: Отправить Мерет: я опаздываю?   — SMS без подтверждения не уходит
Вы: Да
Akyl: Отправлено
```

## Состояние: этап 1 закрыт

Команду можно сказать голосом или набрать. Распознаёт системный движок
Android в режиме «только на устройстве» — в сеть он не ходит. Замена на
T-one (точнее на именах) идёт этапом 2, см. [docs/speech.md](docs/speech.md).

| Что | Состояние |
|---|---|
| Обращение «Макс» / «Эй, Макс» / «Алым» — на телефоне, T-one + Silero VAD | готово, [замеры](docs/voice.md#обращение-почему-не-отдельная-kws-модель) |
| Фон: свёрнуто, экран заблокирован, убрано из недавних, после перезагрузки | готово (microphone-служба; перезагрузка — если Alym AI выбран помощником) |
| Разговор без повторного «Макс», перебивание ответа | готово |
| Голосовой ответ: лучший офлайн-голос, приглушение музыки | готово |
| Звонки, SMS с подтверждением, напоминания, будильник, таймер, фонарик | готово |
| Калькулятор, музыка (пауза/трек), заряд, память, SOS | готово |
| Личное (SMS, звонки, заметки) на заблокированном экране — только после разблокировки | готово, настраивается |
| Панель отладки голоса: фазы, задержки, журнал | готово |
| Своя NLU-модель, LLM | нет: приложение офлайн, см. docs/voice.md |

Подробный план — [docs/roadmap.md](docs/roadmap.md).

## Запуск

```bash
cd app
flutter pub get
flutter run            # нужен Android 10+ (API 29)
```

Тесты и проверки:

```bash
cd app
flutter analyze                                   # должно быть чисто
flutter test                                      # ~290 тестов
flutter test --coverage                           # покрытие ядра ~89%
flutter test --update-goldens test/presentation   # пересобрать снимки экранов
```

Модели для этапа 2 — [docs/models.md](docs/models.md):

```powershell
powershell -ExecutionPolicy Bypass -File tools\fetch_models.ps1
```

Иконки и фирменный знак пересобираются из кода:

```bash
python tools/make_icons.py     # нужен Pillow
```

## Устройство

```
речь → VAD → STT → NLU → диспетчер диалога → навык → Kotlin → звонок/SMS
                                     ↓
                              голосовой ответ
```

Каждый слой стоит за интерфейсом: `RuleBasedNlu` меняется на `MlNlu`, а
`ManualTextStt` на `TOneStt` правкой одной строки в `app/lib/main.dart`.
Ядро — чистый Dart без Flutter и Android, поэтому все сценарии из ТЗ
проверяются юнит-тестами: см. `app/test/domain/scenarios_test.dart`.

Подробнее — [docs/architecture.md](docs/architecture.md), решения и их причины —
[docs/adr/](docs/adr/).

## Приватность

Голос, распознанный текст и контакты не покидают телефон. Разрешения
`INTERNET` в релизном манифесте нет — это можно проверить, и это проверяет CI.
В debug- и profile-сборках его добавляет сам Flutter, иначе не работает
hot reload.
