# ml — своя NLU-модель

Этот каталог относится к **этапу 3** (ТЗ, раздел 6). На этапе 1 приложение
работает на правилах (`app/lib/data/nlu/rule_based_nlu.dart`), и это сделано
намеренно: правила дают нижнюю границу качества, с которой в отчёте
сравнивается обученная модель.

## Что уже есть

| Файл | Состояние | Что делает |
|---|---|---|
| `data_gen/vocab.py` | готово | Имена, падежи, ласковые формы, типовые тексты SMS |
| `data_gen/templates.py` | готово | Шаблоны фраз по намерениям |
| `data_gen/generate.py` | готово | Генерация датасета с BIO-разметкой и шумом STT |
| `train.py` | каркас | Baseline и модели v1/v2 (ТЗ, раздел 6) |
| `evaluate.py` | каркас | Accuracy намерения, F1 по слотам, задержка |
| `export.py` | каркас | int8 -> ONNX / TFLite |

## Генерация датасета

Скрипт не требует зависимостей, только стандартную библиотеку:

```bash
python data_gen/generate.py --count 50000 --out data/train.jsonl
python data_gen/generate.py --count 5000  --out data/val.jsonl --seed 7
```

Формат строки — одна фраза:

```json
{"text": "напиши мерет что я опаздываю",
 "intent": "SMS",
 "tags": ["O", "B-CONT", "O", "B-MSG", "I-MSG"]}
```

Токены и теги согласованы по длине — это проверяется при генерации.

## Правила, которые должны совпадать с приложением

Падежи, уменьшительные формы и транслитерация продублированы в Dart
(`app/lib/data/contacts/`) и в Python (`data_gen/vocab.py`). Это осознанное
дублирование: на устройстве не нужен pymorphy3, а в датасете нужен полный
охват форм. Расхождения ловит сверка — см. `docs/adr/0003-nlu-own-model.md`.
