# Обращение «Макс»

Описание перенесено в [voice.md](voice.md): как устроено обращение,
фоновый режим, замеры распознавания и ограничения Android.

Коротко: микрофон открывает только `VoiceManager` (Dart) через единственный
`AudioRecord` в `MicHub.kt`; в фоне запись держит foreground-служба
`VoiceService` типа microphone. Цикл системного `SpeechRecognizer`, из-за
которого микрофон щёлкал и включался сам, удалён.
