# Обновление помощника: интерфейс, контакты и обращение «Макс»

## Что работает без интернета

- Команды «Макс, какое сегодня число», «Макс, скажи время», «Макс, как дела».
  Время и дата берутся из часов телефона. Короткий разговор реализован готовыми
  ответами, а не генеративной моделью.
- Звонки, громкая связь и SMS; сообщения отправляются после подтверждения.
- «Напиши этому человеку сообщение Привет, как дела?» берёт предыдущего
  адресата из контекста (60 секунд), отделяет служебные слова, сохраняет регистр
  и пунктуацию текста. Без контекста помощник спрашивает адресата.
- Названия мама/Ejem/Ejemjan и папа/Kaka/Kakam/Kakamjan. При нескольких
  совпадениях требуется выбор; произвольное имя не считается родственником.
- В настройках можно назначить конкретный контакт мамой или папой. ID контакта
  хранится локально через shared_preferences и сохраняется после перезапуска.
  Удалённый контакт нужно назначить заново, автоматической подмены нет.
- Nunito и Lottie входят в APK. Для отображения интерфейса сеть не требуется.

## Настройка Samsung A17 / Android 16

1. Открыть Alym AI и предоставить доступ к микрофону, контактам, звонкам и SMS.
2. Открыть «Настройки помощника» (значок ползунков в шапке).
3. Нажать «Выбрать Alym AI помощником» и выбрать приложение в системных
   настройках цифрового помощника. Затем вернуться в приложение.
4. Включить «Откликаться на Макс» для работы внутри приложения. Для работы
   после сворачивания отдельно включить «Слушать при закрытом приложении» и
   разрешить уведомления.
5. Проверить строку «Микрофон включён» и сказать при разблокированном экране:
   «Макс, какое сегодня число?». Для этой проверки не нужны звонки или SMS.

Выбор системного помощника делает сам пользователь. Приложение не меняет
помощника скрытно. Android переподключает VoiceInteractionService после
перезагрузки; слушание возобновляется после разблокировки. Принудительная
остановка приложения и ограничения Samsung могут препятствовать этому.
Для Samsung при необходимости проверьте список приложений в глубоком сне.

## Ограничения фонового режима

Это экспериментальное последовательное распознавание через
SpeechRecognizer.createOnDeviceSpeechRecognizer (Android 12+), а не отдельная
энергоэффективная модель обнаружения ключевого слова. Системный движок может
делать паузы между сеансами, подавать звуковые сигналы и расходовать батарею.
Потребление и процент пропусков на Samsung A17 пока не измерены.
На Android 10–11 фоновое обращение отключено; обычные команды доступны через UI.

Микрофон закрывается при блокировке экрана, перед озвучкой и при передаче
управления обычному распознаванию. Во время телефонного/VoIP-разговора новые
сеансы не запускаются. Команда передаётся через защищённый сеанс системного
помощника и временный внутренний буфер, а не из внешних Intent-параметров.
Для голосового подтверждения SMS приложение ждёт окончания озвучки, после
чего автоматически слушает ответ.

Нужны установленный русский офлайн-язык распознавания и офлайн-голос TTS.
Если их нет, приложение сообщает об ошибке, не переключает фоновый режим
на сетевое распознавание. Громкая связь запрашивается через штатный
TelecomManager.EXTRA_START_CALL_WITH_SPEAKERPHONE; окончательное поведение
зависит от звонилки и прошивки.

## Какие модели рассмотреть

- **Распознавание речи:** [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models)
  — 45 МБ, Apache 2.0, предназначена для мобильных устройств. Это стартовый
  кандидат для локального распознавания, не «мозг» для свободного разговора.
  Нужны замеры качества имён и задержки; модель не заменяет отдельный wake-word
  детектор с малым расходом энергии.
- **Свободный текстовый разговор:** [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B)
  в GGUF-квантизации для llama.cpp. Режим без reasoning и небольшой контекст
  уместны как первый эксперимент на телефоне. Скорость и качество русского
  языка на A17 ещё не измерены; это не обещание качества облачных ассистентов.

**Эти модели сейчас не включены в APK и не загружаются приложением.**
Из среды сборки загрузка Vosk не удалась из-за DNS/сетевой недоступности.
Для подключения нужны соответствующий runtime, импорт модели и отдельные
проверки на устройстве. Простое скачивание файла не изменит текущую сборку.
Текущая сборка использует системное офлайн-распознавание и разбор команд на
правилах. Это позволяет выполнять перечисленные действия без загрузки LLM.

## Проверки

Автоматические тесты проверяют разбор фраз, неоднозначные контакты, сохранение
назначений, удалённые контакты, одинаковые имена, подтверждение SMS, сброс
устаревшего подтверждения, скорость поиска и снимки интерфейса.

Проверку реального распознавания «Макс», работы после перезагрузки и
аудиомаршрута звонка нужно провести на телефоне. Тесты используют поддельную
телефонию и не совершают звонков/отправок сообщений.
